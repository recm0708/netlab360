# Archivo temporal de continuidad

Este directorio **no forma parte de los entregables técnicos o académicos finales de NETLAB360**. Conservamos aquí los planes de trabajo, bitácoras de sesiones, guiones editoriales, listas de seguimiento, registros históricos de issues y puntos de reanudación producidos durante la ejecución del proyecto.

La reubicación mantiene íntegro el contenido original de cada documento. La estructura interna reproduce las rutas previas, bajo `docs/_temporal_continuidad/`, para facilitar consultas entre jornadas, sin confundir ese histórico con la documentación técnica vigente.

Los archivos ubicados fuera de esta carpeta contienen la arquitectura, el código, las configuraciones, las decisiones técnicas, las pruebas, la aceptación y las evidencias verificadas del proyecto. La documentación final no debe remitir a este directorio como fuente de resultados técnicos cuando existan registros originales.

**Al cerrar las ocho fases y completar la entrega**, eliminaremos este directorio de `main` una vez confirmada su innecesariedad. La eliminación del árbol de archivos no reescribe destructivamente el historial Git. No incluiremos este material temporal en el TAR de entrega final.
