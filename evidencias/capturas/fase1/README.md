# Capturas S01 — Pruebas iniciales

Versionamos **83 PNG** de la línea base de NETLAB360. Documentamos IPAM y segmentación, FRRouting/OSPF dual-WAN y recuperación, VLAN/ACL/HTTP, agregación LACP, observabilidad inicial, diagnóstico por reglas y las primeras ejecuciones Ansible/OpenTofu.

Las imágenes corresponden a resultados ejecutados, no a disponibilidad permanente ni a servicios de producción. No añadimos capturas de endurecimiento SSH, consola VMware o inventario de firmware a este conjunto: esos controles están registrados en la [issue de seguridad](https://github.com/recm0708/netlab360/issues/38).
