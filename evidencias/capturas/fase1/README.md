# NETLAB360 — Evidencias oficiales de la fase 1 (S01)

**83 PNG originales versionadas**, correspondientes a las pruebas iniciales verificables de NETLAB360. El catálogo técnico comprende la preparación de IPAM y capas de red; configuración y operación FRRouting/OSPF; conmutación principal/respaldo; VLAN, HTTP/ACL; mecanismos virtuales LACP y active-backup; observabilidad y alertas; diagnóstico estadístico por reglas; y primeros procedimientos OpenTofu/Ansible.

La lectura de cada captura debe ajustarse a la condición que demuestra: una ruta observada no equivale a disponibilidad constante, una regla disparada no acredita entrega externa de mensajes y un manifiesto OpenTofu de metadatos no representa despliegue automático de routers.

Las rutas, tamaños, SHA-256 y hashes de objetos Git se comprueban mediante el [catálogo de integridad](../../manifiestos/MAPA_RENOMBRADO_FASE1_2026-10-25.csv) y el [manifiesto de evidencias complementarias](../../manifiestos/MANIFIESTO_SHA256_CAPTURAS_2026-10-25.csv). Los resultados representativos del informe están descritos en [selección de figuras](../../../docs/entregables/04-seleccion-figuras-y-tablas-s01.md).
